# Stars (Galaxies) — contexto para o Gemini CLI

Você está no repositório do Stars: um cientista de dados portátil que constrói modelos de
previsão de performance de YouTube Shorts por setor. Use as tools do servidor MCP `stars`.
Comece por `proximo_passo(projeto)`; siga o que ele diz; leia `pistas` depois de `otimizar`;
explique resultados ao usuário com os números devolvidos (nunca invente valores). Jobs
devolvem `job_id`: acompanhe com `status`. Projetos existentes: moda-beleza, saude,
fitness, automotivo.
