# 05 · UI (console humano)

React 19 + Vite + TypeScript, em `ui/`. CSS próprio em `ui/src/index.css` (Tailwind está
instalado, mas não é usado). Ícones Material Symbols, fonte Inter. Rota por hash
(`#inicio`, `#analisar`, …). Fala com a API em `/api` (proxy do Vite para `:8000`).

## Arquivos

| arquivo | papel |
|---|---|

| `api.ts` | cliente tipado da API (`pedir`), tipos (`Experimento`, `Receita`, `Analise`, `Faixa`, `Acompanhamento`, `Curva`, `ProximoPasso`, …), `receitaTexto` |

## Estado e dados

Sem gerenciador de estado: `useCarga` por tela, `recarregar` após ações. O projeto atual e
a tela ficam em `App.tsx`; o modo vem de `api.projeto`. Tema (`dark`/`light`) em
`localStorage` (com try/catch). Tudo que vem da API é tipado em `api.ts`; quando um campo
novo nasce no backend, ele entra ali primeiro.

## Modo e estilo

`document.documentElement.dataset.modo` (`automatico` / `cientista`) e `dataset.theme`
controlam tokens CSS: automático em azul, cientista em roxo vivo pulsando (inspiração
Claude), contorno brilhante na cor do modo, glassmorphism nos cartões. Trocar o modo (chip
do topo ou card do Início) dispara a onda a partir do chip e a classe `ressoando` na casca.
Tudo enquadrado na janela: a página não rola; só os painéis internos (feed de projetos,
conteúdo) rolam.

## Banner de andamento

Enquanto um job roda em outro processo (MCP ou CLI), `App.tsx` mostra operação, nº de
etapas, última etapa (nome + entrada resumida) e tempo decorrido. A fonte é o
`andamento.json` escrito pelo `trace`, lido pela API sem abrir o DuckDB.

## Rodar

```bash
cd ui && npm install && npm run dev      # 127.0.0.1:5173 (use --host 127.0.0.1 se o IPv6 atrapalhar)
npx tsc --noEmit -p .                    # checagem de tipos
```
